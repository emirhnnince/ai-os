Atomik A/B OTA Güncelleme

Yeni sürüm yayınlandığında tüm AI OS kullanıcıları tek tıkla veri kaybı olmadan SquashFS güncellemesi alır.

3 Adımda USB Live Kurulumu

Herhangi bir bilgisayarda USB'den başlatın (UEFI & Legacy BIOS destekli).

1. ISO veya USB Aracını İndirin

Yukarıdan AI OS Live ISO dosyasını indirin veya Windows/Linux USB hazırlama aracını alın.

2. USB Belleğe Yazdırın

Windows'ta PowerShell aracımızı veya Rufus/Etcher kullanın (en az 8 GB USB önerilir):

.\Write-AIOS-USB.ps1 -IsoPath .\ai-os.iso

3. USB'den Boot Edin

PC açılışında Boot Menüsünden (F12/F11/ESC) USB belleğinizi seçin ve AI OS Persistence moduyla başlayın.

Sürüm Güncelleme (OTA) Mimarisi

Bu web sitesi aynı zamanda AI OS işletim sistemlerinin resmi güncelleme sunucusudur.

AI OS içindeki OTAUpdater doğrudan bu sitedeki /manifest.json uç noktasını kontrol eder. GitHub Actions üzerinden yeni bir sürüm derlendiğinde manifest güncellenir ve tüm kurulu USB sistemler otomatik olarak yeni sürümü görür.
