USB Kurulum Rehberi

Sadece birkaç dakikada kendi taşınabilir AI işletim sisteminizi hazırlayın.

1

ISO Dosyasını Alın

Yukarıdaki bağlantıdan ai-os-v2.1.0-amd64.iso dosyasını indirin veya USB aracını çalıştırın.

2

USB Belleğe Yazdırın

Windows PowerShell'de hazırlama aracımızı çalıştırın (Rufus / BalenaEtcher de kullanabilirsiniz):

.\Write-AIOS-USB.ps1 -IsoPath .\ai-os.iso
3

Boot Edin

Bilgisayarınızı yeniden başlatıp F12 / F11 tuşuyla USB'yi seçin. AI OS anında hazır!
